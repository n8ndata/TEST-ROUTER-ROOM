# 📖 คู่มือการเชื่อมต่อ Google Sheets กับ Web App แผนก ROUTER

ระบบนี้รองรับการทำงานกับ Google Sheets แบบ **Real-time** และทำงานร่วมกับแผ่นงาน **"รายชื่อพนักงาน"** ตามที่กำหนดไว้

---

### ขั้นตอนที่ 1: สร้าง Google Sheets
1. เปิด [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตใหม่
2. ตั้งชื่อไฟล์ เช่น `ระบบบันทึกข้อผิดพลาด แผนก ROUTER`

---

### ขั้นตอนที่ 2: ติดตั้งสคริปต์ Google Apps Script
1. ที่เมนูด้านบนของ Google Sheet คลิก **ส่วนขยาย (Extensions)** ➔ **Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด
3. คัดลอกโค้ดทั้งหมดจากไฟล์ `google-apps-script/Code.gs` ในโปรเจกต์นี้ มาวางลงในหน้าต่าง Apps Script
4. คลิกไอคอน **บันทึก (Save)** หรือกด `Ctrl + S`

---

### ขั้นตอนที่ 3: สั่งรันเตรียมตารางอัตโนมัติ (1-Click Setup)
1. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน `setupSystem`
2. คลิกปุ่ม **เรียกใช้ (Run)**
3. ระบบจะขออนุญาตสิทธิ์เข้าถึง (Authorization Required) ให้คลิก:
   - **ตรวจสอบสิทธิ์ (Review Permissions)**
   - เลือกบัญชี Google ของท่าน
   - คลิก **ขั้นสูง (Advanced)** ➔ คลิก **ไปที่... (ไม่ปลอดภัย) / Go to ... (unsafe)**
   - คลิก **อนุญาต (Allow)**
4. เมื่อรันเสร็จ กลับไปดูที่ Google Sheet จะเห็นแผ่นงาน 2 แผ่นถูกสร้างและจัดรูปแบบให้อัตโนมัติ:
   - 📑 **`รายชื่อพนักงาน`** : พร้อมรายชื่อพนักงานตัวอย่าง, รหัสพนักงาน, กะ, ตำแหน่ง
   - 📑 **`บันทึกความผิดพลาด`** : พร้อมหัวตารางสีสวยงามและข้อมูลตัวอย่าง

> 💡 **ข้อสังเกต:** ท่านสามารถเพิ่ม ลบ หรือแก้ไขรายชื่อพนักงานในแผ่นงาน `รายชื่อพนักงาน` ได้ตามต้องการ ระบบ Web App จะดึงรายชื่อนี้มาแสดงใน Dropdown ให้เลือกโดยอัตโนมัติ!

---

### ขั้นตอนที่ 4: เผยแพร่เป็น Web App (Deploy)
1. ที่มุมขวาบนของ Apps Script คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** ➔ **การทำให้ใช้งานได้รายการใหม่... (New deployment)**
2. คลิกที่ไอคอนเฟือง ⚙️ ด้านซ้าย เลือกประเภท **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `ROUTER Error Tracking API v1`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **`ทุกคน (Anyone)`** *(สำคัญมาก: ต้องเลือก "ทุกคน" เพื่อให้ Web App สามารถส่งและรับข้อมูลได้)*
4. คลิก **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
   *(ตัวอย่าง: `https://script.google.com/macros/s/AKfycbx.../exec`)*

---

### ขั้นตอนที่ 5: นำ URL ไปใส่ใน Web App
1. เปิดหน้าเว็บ Web App ของแผนก ROUTER
2. คลิกปุ่ม **"⚙️ ตั้งค่าระบบ"** หรือเข้าผ่าน **"โหมดผู้ดูแล (Admin)"**
3. วาง Web App URL ที่คัดลอกมาลงในช่อง **"Google Apps Script Web App URL"**
4. คลิกปุ่ม **"ทดสอบการเชื่อมต่อ & ซิงค์ข้อมูล"**
5. สถานะจะเปลี่ยนเป็น **🟢 เชื่อมต่อแล้ว (Connected)** พร้อมดึงรายชื่อพนักงานและบันทึกข้อผิดพลาดจาก Google Sheet มาแสดงทันที!

---

## 🔐 ความปลอดภัยของโหมด Admin (Server-side)
- PIN จะถูก **แฮชด้วย SHA-256 + Salt** แล้วเก็บใน **Script Properties** ของ Google Apps Script (ฝั่งเซิร์ฟเวอร์) ไม่ส่ง/เก็บ PIN เป็นข้อความดิบในเบราว์เซอร์หรือใน Google Sheet
- เมื่อยืนยัน PIN สำเร็จ เซิร์ฟเวอร์จะออก **Session Token** (CacheService, อายุ 8 ชั่วโมง) กลับมาให้เบราว์เซอร์
- การดำเนินการที่สำคัญ (เช่น ลบข้อมูล) ต้องส่ง Token นี้ไปด้วย และเซิร์ฟเวอร์จะตรวจสอบความถูกต้องก่อนดำเนินการ — แม้แก้ไขโค้ดฝั่ง client ก็ไม่สามารถลบข้อมูลได้โดยไม่มี Token ที่ถูกต้อง
- **PIN เริ่มต้น:** `1234` (ถูกแฮชแล้วตอนเรียกใช้ครั้งแรก) — ควรเปลี่ยนทันทีหลังติดตั้ง
- **เปลี่ยน PIN:** ต้องยืนยัน PIN ปัจจุบันก่อน (ฝั่งเซิร์ฟเวอร์) แล้วเซิร์ฟเวอร์จะออก Token ใหม่และยกเลิก Token เก่า
- **การป้องกันการเดารหัส:** ฝั่งเบราว์เซอร์จำกัด 5 ครั้ง → ล็อค 30 วินาที
- **โหมดออฟไลน์ (ไม่ได้ตั้งค่า GAS URL):** ระบบจะใช้การตรวจ PIN แบบ client-side (SHA-256 ใน localStorage) เป็น fallback แต่การลบข้อมูลจะทำได้เฉพาะในเครื่องเท่านั้น

### Action ใหม่ที่เพิ่มใน `doPost`
| Action | พารามิเตอร์ | ผลลัพธ์ |
|---|---|---|
| `verifyAdminPin` | `{ pin }` | `{ status, token, message }` |
| `changeAdminPin` | `{ currentPin, newPin, adminToken }` | `{ status, token, message }` |
| `deleteIncident` | `{ id, adminToken }` | ต้องมี Token ที่ถูกต้อง มิฉะนั้นคืน `code: "UNAUTHORIZED"` |
- หากยังไม่ได้ใส่ URL หรือขณะไม่มีอินเทอร์เน็ต ระบบจะใช้ข้อมูลจำลอง (Mock Data) และบันทึกลงในเครื่อง (`localStorage`) อัตโนมัติ ทำให้ทดลองใช้งานและบันทึกข้อมูลได้ทันทีโดยไม่สะดุด
- เมื่อต่อ Google Sheet ระบบจะซิงค์ข้อมูลให้เป็นปัจจุบันอัตโนมัติทุก ๆ 20-30 วินาที หรือเมื่อมีการบันทึกข้อมูลใหม่
