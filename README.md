# 🛠️ ROUTER Dept - ระบบบันทึกและติดตามข้อผิดพลาดในการปฏิบัติงาน

Web Application ที่พัฒนาขึ้นสำหรับ **แผนก ROUTER** โดยเฉพาะ เพื่อใช้บันทึก ตรวจสอบ และวิเคราะห์ข้อผิดพลาดในการปฏิบัติงานของพนักงาน (เช่น ตั้งโปรแกรมผิด, ดอกเราเตอร์หัก/สึก, จิ๊กหลวม, ตัดกินชิ้นงานเกินสเปก, ไม่ตรวจ First Piece ฯลฯ) พร้อมเชื่อมโยงข้อมูลกับ **Google Sheets** แบบ Real-time และมีระบบหลังบ้าน (Admin Back-office)

   - ใช้พื้นที่หน้าจอได้เต็มที่ (Wide Layout, 4 คอลัมน์ตัวชี้วัด KPI, 2 คอลัมน์กราฟวิเคราะห์)

   - เลย์เอาต์และชาร์ตจะปรับขนาดตัวเองอัตโนมัติตามการหมุนหน้าจอ (Orientation Change)

9. 📝 **ฟอร์มทันสมัย**:
   - ดีไซน์สวยงาม พร้อมปุ่มลัด (Quick Chips) สำหรับประเภทความผิดพลาดที่พบบ่อย และการเลือกความรุนแรงด้วยปุ่ม Badge สี
10. 👆 **พื้นที่ปุ่มเหมาะกับการกดด้วยนิ้ว**:
    - พื้นที่สัมผัสขั้นต่ำ 48px พร้อมเอฟเฟกต์การกด (Active Press Feedback)
11. 🔐 **Modal Admin รองรับ Safe Area**:
    - ป้องกันขอบจอ Notch และขอบโค้งของ iPhone / สมาร์ตโฟนยุคใหม่ด้วย `env(safe-area-inset-*)`
    - ล็อกด้วยรหัส PIN 4 หลัก (ค่าเริ่มต้น: **1234**) พร้อมแป้นตัวเลขบนหน้าจอ
12. 🌙 **ปรับโหมด Dark Theme / White Theme อัตโนมัติตามช่วงเวลา**:
    - เวลา 06:00 - 17:59 น. ➔ โหมดสว่าง (White Theme)
    - เวลา 18:00 - 05:59 น. ➔ โหมดมืด (Dark Theme)
    - สามารถกดสลับโหมดได้เองตลอดเวลา (Auto / Dark / Light) ผ่านปุ่มบนแถบเมนูด้านบน

    - ปิด/ลดแอนิเมชันอัตโนมัติหากผู้ใช้งานตั้งค่า Accessibility ในระบบปฏิบัติการ
14. 🖥️ **ไม่มี Horizontal Scroll กวนใจ**:
    - กำหนด `max-width: 100vw` และ `box-sizing: border-box` ทั้งระบบ
15. ☁️ **ระบบหลังบ้าน & เชื่อมโยง Google Sheets แบบ Real-time**:
    - ดึงรายชื่อพนักงานสดจากแผ่นงานชื่อ **"รายชื่อพนักงาน"**

## 🚀 วิธีเปิดใช้งาน Web App

### วิธีที่ 1: เปิดไฟล์ตรง ๆ บนคอมพิวเตอร์
- ดับเบิลคลิกเปิดไฟล์ `index.html` ใน Google Chrome, Microsoft Edge, Safari หรือ Browser ใดก็ได้ ระบบจะทำงานทันทีพร้อมข้อมูลตัวอย่าง!

### วิธีที่ 2: รันผ่าน Local Server (แนะนำ)
เปิด PowerShell ในโฟลเดอร์นี้ แล้วสั่ง:
```powershell
python -m http.server 8080
# จากนั้นเปิดบราวเซอร์ไปที่ http://localhost:8080
```
หรือหากใช้ Node.js:
```powershell
npx serve .
```

## 🔗 วิธีเชื่อมต่อกับ Google Sheets ของท่าน (ภายใน 3 นาที)

1. เปิด [Google Sheets](https://sheets.new) ขึ้นมา 1 ไฟล์
2. ที่เมนูเลือก **ส่วนขยาย (Extensions)** ➔ **Apps Script**
3. ลบโค้ดเดิม แล้วนำโค้ดในไฟล์ [Code.gs](file:///c:/Users/SARAWUT/OneDrive/Desktop/TESTNEW/google-apps-script/Code.gs) ไปวาง
4. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน **`setupSystem`** แล้วกด **เรียกใช้ (Run)** (กดยอมรับสิทธิ์ครั้งแรก)
   - *คำสั่งนี้จะสร้างแผ่นงาน **"รายชื่อพนักงาน"** และ **"บันทึกความผิดพลาด"** พร้อมหัวตารางและข้อมูลตัวอย่างให้ทันที 100%!*
5. กดปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** ➔ **การทำให้ใช้งานได้รายการใหม่... (New deployment)**
   - ชนิด: **เว็บแอป (Web App)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** *(สำคัญมาก)*
6. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
7. กลับมาที่หน้า Web App กดปุ่ม **Admin** ➔ ใส่ PIN ➔ ในศูนย์ควบคุม Admin กด **"แก้ไขการเชื่อมต่อ"** วาง URL ลงในช่องแล้วกด **บันทึกและซิงค์ทันที** *(ปุ่มตั้งค่าจะแสดงในโหมด Admin เท่านั้น)*

## 🔐 รหัสผ่านเข้าโหมด Admin
- **รหัส PIN เริ่มต้น:** `1234` *(แสดงเฉพาะในเอกสารนี้ ไม่แสดงบนหน้าเว็บ)*
- **การตรวจ PIN ทำฝั่งเซิร์ฟเวอร์:** PIN จะถูก **แฮชด้วย SHA-256 + Salt** แล้วเก็บใน **Script Properties** ของ Google Apps Script (ไม่เก็บในเบราว์เซอร์/Google Sheet) — ต้องตั้งค่า GAS URL ก่อนจึงจะใช้โหมดนี้
- **โหมดออฟไลน์ (ไม่ได้ตั้งค่า GAS URL):** ระบบจะใช้การตรวจ PIN แบบ client-side (SHA-256 ใน localStorage) เป็น fallback
- **Session Token:** เมื่อยืนยัน PIN สำเร็จ เซิร์ฟเวอร์จะออก Token (อายุ 8 ชั่วโมง) — การลบข้อมูลต้องมี Token ที่ถูกต้อง มิฉะนั้นเซิร์ฟเวอร์จะปฏิเสธ (`UNAUTHORIZED`)
- **การเปลี่ยนรหัสผ่าน:** ต้องยืนยัน PIN ปัจจุบันก่อนเสมอ (ตรวจสอบฝั่งเซิร์ฟเวอร์) ทำได้จากหน้าจอ Admin Control Panel
- **การป้องกันการเดารหัส (Brute-force):** กรอกผิด 5 ครั้งติดต่อกัน ระบบจะล็อคชั่วคราว 30 วินาที
- **เซสชันปลอดภัยโดยอัตโนมัติ:** ล็อคโหมด Admin เมื่อไม่ใช้งาน 15 นาที, ปิดเบราว์เซอร์ หรือกดปุ่ม "ล็อคโหมด Admin"
- หากเปิดแอพจากระบบเดิม ระบบจะย้าย PIN เดิมไปเก็บแบบเข้ารหัสให้อัตโนมัติตั้งแต่การเปิดใช้งานครั้งแรก (PIN เดิมยังใช้ได้เช่นเดิม)
