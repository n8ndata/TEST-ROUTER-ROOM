ตั้งค่าการเชื่อมต่อ Google Sheets

วิธีเชื่อมต่อกับ Google Sheets
  1. เปิด Google Sheets ➔ ส่วนขยาย (Extensions) ➔ Apps Script
  2. วางโค้ดจากไฟล์ google-apps-script/Code.gs
  3. รันฟังก์ชัน setupSystem หนึ่งครั้งเพื่อสร้างชีตและข้อมูลเริ่มต้น
  4. กด Deploy เป็น Web App (ดำเนินการในฐานะ: ฉัน, สิทธิ์เข้าถึง: ทุกคน / Anyone)
  5. คัดลอก URL ที่ลงท้ายด้วย /exec มาวางในช่องด้านล่าง
* หากปล่อยว่าง ระบบจะทำงานในโหมดออฟไลน์และเก็บข้อมูลในเครื่อง (LocalStorage)
